# SiteJLB

Site institucional simples e moderno da **JLB Asset Management**, com foco em conversão para atendimento via WhatsApp Business.

## Estrutura
- Header com menu: Início, Sobre, Serviços e Contato.
- Hero com proposta de valor e botão principal para WhatsApp.
- Seção Sobre com resumo institucional.
- Seção Serviços com 3 cards.
- CTA final destacada.
- Footer institucional com ano automático e atalho para WhatsApp.
- Botão flutuante de WhatsApp.

## Personalização
1. Abra `index.html`.
2. Substitua `SEU_NUMERO_AQUI` em todos os links `https://wa.me/...` pelo número real (com DDI/DD).
3. Ajuste textos, se necessário.

# SiteJLB

Site institucional simples e moderno da **JLB Asset Management**, com foco em conversão para atendimento via WhatsApp Business.

## Arquivos
- `index.html`: estrutura do site (header, hero, sobre, serviços, CTA e footer)
- `styles.css`: identidade visual premium (preto + dourado), responsividade e animações suaves
- `script.js`: menu mobile e ano dinâmico no rodapé

## Personalização do WhatsApp
Procure por `SEU_NUMERO_AQUI` e substitua pelo número real no formato internacional.

Exemplo:
- `https://wa.me/5511999999999?text=Ol%C3%A1%2C%20gostaria%20de%20saber%20mais%20sobre%20a%20consultoria%20financeira.`
